Disaster Recovery & Restore Commands

1. Restore PostgreSQL 16 (Production)

Execute inside or against the Docker container:

docker exec -i fems-production pg_restore -U fems_admin -d fems_production --clean --if-exists < postgres_fems_production_YYYYMMDD.dump

2. Restore MongoDB 7 Audit DB (Production)

Execute against the MongoDB container:

mongorestore --uri="mongodb://fems_logger:SecureLogsPwd456@127.0.0.1:27017/fems_audit_db?authSource=admin" --archive=mongodb_fems_audit_db_YYYYMMDD.archive --gzip --drop

3. Restore Staging PostgreSQL & MongoDB

docker exec -i fems-staging pg_restore -U fems_admin -d fems_staging --clean --if-exists < postgres_fems_staging_YYYYMMDD.dump
mongorestore --uri="mongodb://fems_logger:SecureLogsPwd456@127.0.0.1:27017/fems_audit_staging_db?authSource=admin" --archive=mongodb_fems_audit_staging_YYYYMMDD.archive --gzip --drop
